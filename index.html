Regret table (opportunity loss)
How is each statistic calculated?
  • Maximax: for each alternative take its maximum payoff; choose the highest (optimistic).
  • Maximin: for each alternative take its minimum payoff; choose the highest (pessimistic / conservative).
  • Minimax Regret: regret = best payoff in that state − alternative's payoff. Take each alternative's maximum regret; choose the lowest.
  • EMV / Bayes: EMV = Σ (probability × payoff); choose the highest. Requires valid probabilities that sum to 1.

3. Criterion decisions

Each criterion evaluates the full set of alternatives independently. Different criteria may recommend different alternatives.

4. Staged filtering

Stages run in order, and each stage only sees the survivors of the previous one. Eliminated alternatives never return. Statistics are not recalculated between stages (regret benchmarks stay fixed to the full table). If several alternatives tie at the cutoff, all of them survive.
